# P1 – Manejo del estado

**a)** Zustand permite compartir el estado entre componentes sin tener que pasar datos y funciones mediante props. En esta aplicación, el tablero y el modal pueden acceder a las mismas tareas y mantenerse sincronizados.

**b)** Se debe crear un arreglo nuevo para que React y Zustand detecten el cambio de referencia y actualicen los componentes que dependen de ese estado. Si modificamos directamente el arreglo existente, la vista podría no actualizarse.

**c)** Guardar solo el ID evita duplicar información. Así, cuando cambia una tarea, el modal consulta su versión actualizada desde el store y no utiliza una copia que podría quedar desactualizada.
